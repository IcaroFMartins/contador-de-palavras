# Contador de Palavras

Programa em Python que analisa um arquivo de texto e mostra estatísticas
sobre as palavras encontradas.

## Como executar

```bash
python3 main.py
```

Depois, informe o caminho de um arquivo `.txt`.

## Funcionalidades

- Contar o total de palavras
- Contar palavras únicas
- Mostrar as palavras mais frequentes
- Ignorar diferenças entre maiúsculas e minúsculas
- Remover pontuação antes da contagem

## O que aprendi

- Ler arquivos com `pathlib`
- Usar `collections.Counter`
- Trabalhar com strings e listas
- Separar lógica de análise da interface de linha de comando
- Tratar erros de arquivo inexistente
